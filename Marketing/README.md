# Marketing — ScuderiaGuidar

Esta carpeta contiene el material correspondiente a la etapa de **Marketing y Comercialización** del proyecto ScuderiaGuidar.

## Brochure comercial

El brochure fue diseñado para presentar ScuderiaGuidar desde una perspectiva comercial y comunicar de manera simple los principales beneficios del servicio.

La propuesta se basa en ofrecer un servicio de alquiler de vehículos ágil, confiable y adaptable a diferentes necesidades de movilidad.

## Objetivo

Presentar a **ScuderiaGuidar** como una alternativa de rent a car orientada a conectar a cada cliente con una opción de movilidad adecuada a sus necesidades.

## Público objetivo

La propuesta está dirigida principalmente a:

- Turistas que buscan comodidad y libertad para recorrer.
- Profesionales que necesitan movilidad confiable.
- Empresas que requieren soluciones de traslado.

## Propuesta de servicio

ScuderiaGuidar ofrece soluciones de movilidad mediante un servicio de alquiler de vehículos que dispone de diferentes categorías y alternativas.

El sistema busca brindar una experiencia:

- Ágil.
- Simple.
- Segura.
- Organizada.
- Adaptada a las necesidades de cada cliente.

## Web promocional

Como complemento del brochure se desarrolló una página promocional utilizando **WordPress**.

La web se encuentra disponible en:

**https://wp3.scuderiaguidar.com.ar/**

Incluye las siguientes secciones:

- Home.
- Nuestro Sistema.
- Precio.
- Pedí una Demo.
- Novedades.
- Contacto.

También incorpora:

- Formularios de contacto.
- Llamadas a la acción.
- Acceso mediante WhatsApp.
- Presentación de funcionalidades.
- Modalidades comerciales.
- Solicitud de demo.
- Promoción del 20% de descuento.

## Identidad visual

La identidad de ScuderiaGuidar utiliza principalmente una combinación de colores amarillos, negros y tonos neutros, acompañada por fotografías relacionadas con vehículos y movilidad.

El objetivo es mantener una presentación moderna y consistente entre el sistema principal, la web promocional y el material comercial.
