## Finalidad

El documento busca presentar de forma clara y ordenada cómo fue construido ScuderiaGuidar y demostrar el cumplimiento de las consignas establecidas para el trabajo final de Laboratorio III.

## Proyecto

**ScuderiaGuidar** es una plataforma web para alquiler y gestión de vehículos que permite administrar catálogo, clientes, reservas, sucursales y estadísticas.

Además, incorpora servicios externos como Google Maps, correo electrónico y un recomendador inteligente basado en Google Gemini.
